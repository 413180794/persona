# Android 终端模块

已实现只看、手机尺寸接管、冲突确认、VT 网格绘制、宽字符、框线与块字符、帧续传及缺帧恢复、中文组字、修饰键、逐行滚轮、格子点击和 ANSI 读屏降级。终端使用随包附带的 JetBrains Mono，许可见 OFL.txt。颜色随现有 Material 主题变化，按钮保持单行，键栏可横滑。

首帧前始终保留网格视图，按实际布局计算列×行后才请求接管。尺寸变化的防抖参数沿用终端设计。状态提示覆盖在画面上，键栏固定占位，避免状态切换触发窗格反复改尺寸。按下位置作为整次滑动及惯性滚动的格子锚点，每行独立发送一个滚轮事件。

只看时不发送键盘、滚轮或点击。输入经现有 WebSocket 按序发送，断线后不补发输入。进入后台或离开页面时取消任务并退订，交还电脑尺寸。旧 hub 或 node 不支持流时使用现有读屏 HTTP 接口。

## 当前 App 接线

App 已依赖 `:feature:terminal`，`AppServices` 使用唯一活动连接创建 `HubTerminalTransport` 并提供随配对切换的代理；`Root` 已注册 `terminalEntries`，`ShellChat`、默认聊天入口及通知终端兜底均可导航到 `TerminalRoute`。真实输入法、接管与退订恢复仍待验收。

为完成入口和协议转发，最小修改了终端目录以外的 `ChatEntries.kt`、`ChatScreen.kt`、`ServerEvent.kt` 和 `OkHttpHubConnection.kt`；其余协议、HTTP 实现、路由均为新增文件。settings 只追加本模块的 include。

## 验证与范围

两条关键路径测试覆盖手机网格订阅、宽字符、重连续传、缺帧重取、接管冲突、只看输入门禁、退出退订、滚轮拆分、中文组字提交、修饰键和多行粘贴。已编译终端、对话、hub 及 data 模块。

此轮未连真实 hub，未做真机输入法和深浅色截图验证。更多终端设置、历史分页、选择复制、双指切 Agent 等不在本次任务范围内。没有测量性能，性能未实测。
