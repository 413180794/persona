# 飞书加密消息迁移（#689）

## 已接入：读取展示

lark-connector 的 Agent 接口保留旧 `parts` / `textPreview`，新增版本化的 `olk` 展示投影。Hub 转发此字段，改写其中的媒体 URL；iOS 在成功解密时区分正文、对外展示和群密钥分发提示。无法解密时显示公开内容，并标注「加密消息 · 对外展示」；缓存未重新校验时标注「加密消息 · 仅显示公开内容」，不将外显误呈现为正文；普通文字即使含有「加密群密钥分发消息」也不会被误判为系统提示。

使用现有密钥库及 Agent 明文访问授权，不新增解密权限。授权中途撤销或账号变化时，上游不返回明文展示字段。未知或缺失协议版本不使用明文字段。缺失 / null 的公开内容统一视为空数组；单条可选加密投影不完整不阻断整页普通消息。图片仍沿用上游封面，本阶段不接加密图片的密钥或解密下载。

引用消息携带相同的展示信息；聊天引用与输入框引用在锁定、离线缓存、恢复草稿时均标明「对外展示」或「仅显示公开内容」，不会把外显当作被引用的原文。复制只取当前可见正文；加密消息不进入自动翻译。iOS 的消息和引用编码落盘时仅保留公开内容，清除旧文本字段、正文 parts 及结构化投影里的明文；重新打开后由服务器重新验证权限再读取。**此保护只覆盖 iOS 消息快照及引用草稿的编码路径**，不表示所有存储均已清除明文。Hub 的收件箱和 Agent 上下文管线仍可能把旧 `textPreview` 压平后保存为正文（`server/internal/hub/inbox.go`、`lark_agent.go`）；其他消费方需要单独审计。此保护适用于带新投影的消息，无法从旧服务器已经压平的普通文字反推出加密属性。

## 仍待迁移

手机解锁、独立客户端授权、加密发送及历史外显选择继续跟踪 #689 / nwverse/lark-connector#968。本次读取展示不代表这些写入能力已经可用。协议失败不得退回明文发送；不会把 Agent token 当作主人登录凭据。

审查补充：Go 与 Swift 均测试了缺失、null、错误类型的可选投影，以及正常消息与异常投影共存的整页解码。单条异常投影按关闭状态展示；不回退到旧字段中的明文。
