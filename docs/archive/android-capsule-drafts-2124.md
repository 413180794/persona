# 完成提示后的草稿保留（#2124）

## 结果与证据

输入未发送文字后收起，经过完成提示和自动收回，再展开仍保留原草稿；不同会话草稿保持独立，关闭或切配对时清理。用旧版真实复现、生产Compose回归、修版模拟器同路径和APK / lint / 相关测试证明。
