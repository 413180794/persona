01 / 架构

一台 hub，连起你所有的机器。

hub 是一个 Go 写的服务 personad，跑在家里或公司一台常开的机器上（原生二进制或 Docker / NAS）。 手机、手表、网页都只连它；电脑上装 node 服务，经连接器 Persona Link 主动连 hub，或让 hub 来连，不用 SSH、不用 VPN。

hub

状态都在 Postgres

会话、收件箱、设备、配置都在 hub 机器的 Postgres 容器里；聊天、人、群、项目沉淀成 ~/.persona/data 里的文件，文件为主、库做索引。

node

读 transcript，不抢屏幕

node 在 herdr / Orca 里启动和驱动 Agent，用 hooks 接住提问和审批，读 transcript 流式推给手机；终端走 observe 流，不 attach、不改窗格尺寸。

link

不用 SSH，不用 VPN

笔记本主动拨 hub、断了自己重连；地址固定的机器让 hub 来连。一台电脑有几条路时自动去重、选最快的那条。

relay

推送端到端加密

没有 APNs 密钥的 hub 经中继推送：通知正文用手机的公钥加密，中继只看得到密文，通知扩展在手机上解密；锁屏的实时活动是明文。

04 / 快速开始

三步，十分钟。

  1. 1

    在常开的机器上装 hub

    一台就够一个家。会问谁能打开管理界面；需要的话顺便装好默认的终端引擎 herdr。也可以用 Docker 跑在 NAS 上。

    $ curl -fsSL https://personaside.com/install.sh | sh -s -- --hub
  2. 2

    每台电脑装 node 服务

    在 hub 上 personad hub pair --machine <id> 拿到配对链接，在那台电脑上执行；Mac 也可以用菜单栏 App「Persona Link」点几下装好。

    $ curl -fsSL https://personaside.com/install.sh | sh -s -- --node --pair '<配对链接>'
  3. 3

    手机扫码配对

    hub 打印二维码（或在管理界面的「设备」里生成），App 扫一下；二维码里带着公钥指纹，公网直连也能确认连的是你的 hub。

    $ personad hub pair

每次下载都会对照发布的 SHA256SUMS 校验；hub 之后自己检查更新、等空闲时重启，失败自动回滚。

05 / 隐私

你的数据，只在你的机器上。

Persona 没有账号体系，也不收集、不出售任何数据。hub 是你自己部署的，内容都存在你自己的机器里；只有你让 AI 处理某件事时，相关内容才作为对话发给你选的模型服务。

  • 自建状态在 hub 的 Postgres，知识库是你磁盘上的文件。
  • 加密邮箱凭据和模型 Key 用 AES-GCM 加密存储，密钥文件不进数据库。
  • 钉扎公网直连走 TLS，App 钉住配对时拿到的公钥，优先 IPv6。
  • 端到端通知正文用手机的公钥加密，中继只转发密文（实时活动是明文，可自建中继）。
  • 写操作要你点头改日历、发消息、往飞书写，先在手机上确认。

06 / 常见问题

常见问题

要开 VPN 或内网穿透吗？

不用。hub 开着 TLS 端口时，手机经公网直连（优先 IPv6），靠配对时钉住的公钥确认身份；在内网里也照常能连。电脑那边由 Persona Link 主动拨 hub，不需要公网地址。

支持哪些 Agent？

Claude Code、Codex 和 TRAEX、DSH（DeepSeek Harness）、pi / pi-web，跑在 herdr、Herdr App 或 Orca 里。按运行时协议写一个 driver，或者把常驻服务注册成 daemon，就能接入别的。

手机不在身边时 Agent 卡住了怎么办？

需要你的事会推送到手机和手表，锁屏和灵动岛上能看到是哪台电脑的哪个 Agent；点开直接作答。你也可以让 Persona 助手替你巡检。

数据会经过你们的服务器吗？

只有推送。没有自己 APNs 密钥的 hub 经开发者运营的推送中继发送：普通通知的正文用手机的公钥端到端加密，中继看不到；锁屏和灵动岛的实时活动是 iOS 要求的明文，经中继时它能看到。在意的话给 hub 配上自己的 APNs 密钥，或者自己搭一个中继。详见隐私政策。

怎么拿到 App？

iPhone 和 Apple Watch 版现在通过 TestFlight 分发；网页版由 hub 托管，Android 安装包也从 hub 下载。想试用请写信给我们。
