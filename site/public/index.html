01

Agents离开电脑，工作不停

所有电脑上的 Agent，一个列表。

Jarvis 经 SSH 接入你的每台电脑，读取 herdr 里正在跑的 Claude Code、Codex 和 TRAEX。谁在工作、谁卡住了、谁做完了还没看，一眼分清：需要你的排在最前，并且推到锁屏和灵动岛。

  • 实时流式每一次读文件、跑命令、改代码都在对话里展开，思考和工具调用折叠成一行，点开才看细节。
  • 从手机开工选机器、目录和启动器，发一句话就在那台电脑上新开一个 Agent；带图、带文件、带链接都行。
  • 真终端不改窗格尺寸就能看 Agent 的屏幕，需要时接管键盘，滑动就是滚轮。
  • 排队与续聊Agent 工作时发的话会排队，等它这一轮做完自动送进去。

它问你，你在地铁上就能答。

Claude 用 AskUserQuestion 提问、写好计划等批准、要跑一条有风险的命令：这些原本只能坐回电脑前处理的时刻，现在变成手机上的一张卡片。

  • 回答提问点选项，或者写自己的答案，Agent 立刻接着干。
  • 审批计划批准并自动执行、只自动接受编辑，或者带着修改意见打回。
  • 批准工具Bash、写文件、外部操作，逐个放行或拒绝。
  • 不打开 App在通知、Apple Watch 和 Siri 里也能批准第一个待处理。
02

Jarvis一个真正了解你工作的助手

“今天有什么需要我处理的？”

「Jarvis」是跑在 hub 机器上的一个 Claude，有一个常驻的主对话。它能看到你的 Agents、日程、飞书消息、邮件和知识库，也能读写这部 iPhone 上的数据，所以它的回答从你真实的一天出发。

日历提醒事项通讯录照片健康位置 飞书GmailIMAP / SMTP知识库Agents
  • 定时任务“每天早上九点看一眼线上告警”，重复的事交给它，到点在手机上汇报。
  • 会问你需要你拍板时它在手机上提问，替你出面的操作（发消息、发邮件）一律先确认。
  • 有记忆你的习惯、项目、常打交道的人，它会记住并越用越准。
03

收件箱一行一件事

飞书、邮件、Agent 的待办，合成一个列表。

Jarvis 不做第二个飞书，也不做第二个邮件客户端。它把各处找你的事收到一起，让 AI 先分拣：要你处理的在上面，通知和群聊归到一边。

  • AI 分身读完上下文，判断这件事该怎么回，必要时派一个 Agent 去查，再起草一条回复。你改一改，点一下发送。
  • 交给 AI任何一条消息都能一键交给助手处理，处理完自动标记。
  • 文档里的 @我飞书表格、文档里提及你、评论你的地方也会进来，并直接定位到那一行。
04

/agent在飞书任何地方召唤

在群里打一行字，Agent 就开始干活。

在群聊、私聊、话题或文档评论里以 /agent 开头说一句话，hub 会收集所在会话的上下文：前后的消息、引用、话题、提到的文档和知识库，用你配置的最强模型起一个 Agent 处理，再以你的身份回复。

上下文感知是关键：它不是一个只看到一句话的机器人，而是知道这句话在什么场合说的。

05

知识库让 AI 认识你的世界

聊天、人、群、项目，自动沉淀。

Jarvis 把各处的会话全量归档到 hub 机器上的一个目录：文件为主，数据库做索引。AI 会给项目打标、整理压缩后的上下文、记下每个人和每个群在做什么。

助手、AI 分身和你的 Agents 共用这份知识，所以它们回答“这个项目进行到哪了”“上次和谁聊过这件事”时，有据可查。

08

隐私数据只在你自己的机器上

没有我们的服务器

App 只连接你自己部署的 hub。开发者收不到你的代码、消息、邮件或任何使用数据。

凭据加密存储

邮箱凭据和模型 Key 用 AES-GCM 加密后存进 hub 的数据库，密钥文件留在机器上、不进数据库。

替你出面先问你

发消息、发邮件、写手机数据、在飞书里写东西，这些操作都要你在手机上确认。

Google 登录授权

添加 Gmail 走 Google 官方的 OAuth 登录，不需要也不会保存你的 Google 密码。
